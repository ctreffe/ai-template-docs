# Local Review Files

Use this directory directly for returned project-specific documentation review
files containing comments, Track Changes or PDF annotations. Do not add a
format or status subdirectory: files here are returned annotated review copies
by definition.

Freshly generated review files belong in the document's ignored folder below
`output/`, with companion formats together, for example
`output/handbook/handbook.pdf` and `output/handbook/handbook.docx`. This keeps
generated files separate from returned annotations.

All content except this README is ignored by default. Maintained Quarto or
other repository sources remain authoritative. Follow `FEEDBACK_WORKFLOW.md`
before assistant inspection, Git versioning or publication of a returned file.
